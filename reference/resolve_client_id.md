# Workflow helper functions for common multi-step operations Resolve a client_id from a state and client name, erroring if not found

Workflow helper functions for common multi-step operations Resolve a
client_id from a state and client name, erroring if not found

## Usage

``` r
resolve_client_id(state_abbreviation, client_name)
```

## Arguments

- state_abbreviation:

  Two-character state code

- client_name:

  Name of the municipality

## Value

A single client_id
