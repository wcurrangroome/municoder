# Resolve a product_id from a client_id and product name, erroring if not found

Resolve a product_id from a client_id and product name, erroring if not
found

## Usage

``` r
resolve_product_id(client_id, product_name, client_name)
```

## Arguments

- client_id:

  A unique identifier for a client

- product_name:

  Name of the product

- client_name:

  Name of the municipality, used only for the error message

## Value

A single product_id
